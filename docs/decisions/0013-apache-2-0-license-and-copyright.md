# ADR 0013: Apache License 2.0, copyright held personally

- **Status:** accepted
- **Date:** 2026-09-13

## Context

sorting-office is heading toward publication alongside Graftwork Stock, ahead
of a presentation touching on Stock. A pre-publication review found no
`LICENSE` file. With no license, default exclusive copyright applies: a
visitor can read the repository but has no legal right to use, fork, or graft
from it — which blocks going public regardless of what else is in order,
since a repository grafted from is meant to be reused.

Stock hit the identical gap ahead of its own publication and resolved it as
[Stock ADR 0014](stock-0014-license-and-copyright.md): Apache License 2.0,
copyright held by James Rennison individually rather than by "Graftwork" (a
repo name, not a legal entity). That ADR is explicit that the decision does
not extend to sorting-office — a separate repository with its own history and
its own owner conversation. Asked directly, the owner confirmed: mirror
Stock's choice exactly, for the same reasons and the same audience.

**Which license.** The reasoning in Stock ADR 0014 applies here without
modification: a copyleft license would sit wrong against a project meant to
become fully its owner's own thing once grafted; between the permissive
options, Apache-2.0's explicit patent grant is the more "safe to build on"
signal, and sorting-office is heading toward the same kind of public,
taken-seriously audience Stock is.

**Whose name.** Same owner as Stock. "Graftwork" is still a GitHub org, not a
legal entity capable of holding copyright.

## Decision

- **License:** unmodified Apache License, Version 2.0, as `LICENSE` at the
  repository root.
- **Copyright holder:** James Rennison, individually — recorded in `NOTICE`
  as `Copyright 2026 James Rennison`, with `NOTICE`'s first line reading
  `Sorting Office` rather than `Graftwork Stock`, per the identity-rewrite
  step Stock's own graft instructions call out.
- **Vendored third-party content is unaffected.** The OpenSpec skill files
  under `.claude/skills/openspec-*/` are generated by `@fission-ai/openspec`
  and already declare their own MIT license in frontmatter — confirmed
  directly rather than assumed (`license: MIT` in each file's frontmatter).
- **This is a docs-only change**, so per the route table in
  [`docs/RELEASING.md`](../RELEASING.md) it takes the direct route — branch,
  commit, PR — not a full OpenSpec change.

## Consequences

- sorting-office's own files are clearly licensed, unblocking publication.
- Grafting from sorting-office (should that ever happen) now silently carries
  this same license decision forward, the same consequence Stock ADR 0014
  already names for Stock itself.

## Alternatives considered

Same set Stock ADR 0014 weighed, and rejected for the same reasons: MIT
(drops the patent grant for no offsetting benefit), a copyleft license
(contradicts the graft model), attributing copyright to "Graftwork" (not a
legal person), and leaving it unlicensed (the status quo this ADR exists to
fix).
