## Context

Stock `v0.6.0-rc.1` carries this behaviour as two archived changes
(`session-links-not-disclosed`, then `session-link-scope-agent-written-text`).
Its final spec text is what this project adopts. The decisions below are
Stock's, kept because a grafted project that diverges makes every later
re-sync a merge.

## Decisions

**Pattern: `claude\.ai/code/session`, case-insensitive, matched per line.** It
catches both observed forms: a `Claude-Session:` trailer and an
`_Generated by [Claude Code](https://claude.ai/code/session_…)_` footer. It
deliberately has no `https://` in it, so a link written without a scheme is
caught too. The same pattern also appears in Stock's `session-links` workflow;
nothing checks the copies agree (Stock says so in its CHANGELOG).

**Hook stage: `commit-msg`, not `pre-commit`.** The commit message is not a
staged file. At the `commit-msg` stage pre-commit passes the message file's
path as the sole argument, which is what the script expects.

**`default_install_hook_types: [pre-commit, commit-msg]`.** Without it a plain
`pre-commit install` only wires the `pre-commit` stage, and the new hook would
silently never run. With it, the one command everyone already runs installs
both.

**`language: system`, entry `python scripts/check_no_session_link.py`.** The
script is standard library only, so it needs no environment of its own, the
same reasoning as this project's other local hooks.

**The PR/issue scenario is a declared gap, not a test.** What an agent writes
into a pull request or issue body cannot be observed by the suite, the same
limitation *AI Authorship Is Disclosed* lives with. The written reason says
what the `session-links` workflow does and does not cover, copied as it stands
in Stock's `pyproject.toml`.

## Risks

- A contributor who has not run `pre-commit install` gets no hook. The CI
  `commits` job in the companion PR is the backstop, and `--no-verify` skips
  the hook (CI does not).
- The hook only sees commit messages. A link inside a file, a PR title, or a
  comment is not caught here.

## Alternatives considered

- **A `pre-commit`-stage check on file content.** Rejected: the problem is the
  message, which is not a staged file.
- **Strip the link automatically instead of refusing.** Rejected: refusing
  names the line and teaches the agent not to write it; silent rewriting hides
  that the default still adds one.
